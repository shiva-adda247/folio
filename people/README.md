# Adding Yourself

This directory is the source of truth for the People Portfolio. To add yourself:

1. Create a new markdown file named `your-name.md` (lowercase, hyphens for spaces).
2. Use the frontmatter template below.

\`\`\`markdown
---
name: "Your Name"
role: "Your Role"
portfolio: "https://yourportfolio.com"
avatar: "https://yourportfolio.com/avatar.jpg"
location: "Optional Location"
hardware:
  laptop: "Optional Laptop"
  phone: "Optional Phone"
  monitor: "Optional Monitor"
software:
  os: "Optional OS"
  editor: "Optional Editor"
  frameworks:
    - "Optional"
    - "Frameworks"
---
\`\`\`

3. Submit a Pull Request.
