# People Portfolio

An open-source, static website where people list their portfolios, devices, and tools. Inspired by [uses.tech](https://uses.tech).

## Features

- **People Grid**: A clean, responsive grid of people cards.
- **External Links**: Clicking a card takes you directly to the person's portfolio.
- **PR-Driven**: All content is managed via GitHub Pull Requests.
- **No Backend**: Fully static site built with Next.js and Markdown.

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/folio.git
   cd folio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `people/`: Contains markdown files for each person. This is the source of truth.
- `src/`: Next.js source code.
- `public/`: Static assets.
